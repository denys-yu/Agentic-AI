# DOU Live: «Як побудувати AI-агента з нуля»

Благодійний онлайн-майстер-клас, DOU Live, 4 листопада 2026.
Частина аудиторії — новачки, які знають лише Python. Код показується на екрані під час трансляції.

## Демо

- `00_bare_call.py` — голий виклик моделі
- `01_reflection_sql.py` — SQL-агент з reflection
- `02_agent_from_scratch.py` — агентний цикл з інструментами
- `03_multi_agent_sdk.py` — мультиагентна система на OpenAI Agents SDK
- `04_eval.py` — оцінка Демо 1
- `05_planning.py` — запасне демо

Допоміжне в `common/`: `config.py` (константи, моделі, ціни), `db.py` (`connect_ro()`),
`log.py` (логер агентного циклу; `python -m common.log` показує всі блоки без API).

## Правила коду

- Кожен файл демо читається новачком зверху вниз.
- Усе, що показується на екрані (цикл, схеми інструментів, сенсори), лежить у самому файлі демо.
  У `common/` — тільки допоміжне.
- Коментарі українською, назви англійською, короткі функції, без зайвих абстракцій.
- Інструмент для БД скрізь називається `query_db` з параметром `sql` (як на слайдах).
- Логер говорить словами слайда «Агентний цикл»: Модель думає → Обирає дію →
  Код виконує → Бачить результат → Відповідь.

## Безпека

- Ніколи не читай `.env`. Ключ доступний скриптам лише через змінні середовища.
- База тільки на читання: з демо відкривай її через `connect_ro()`.
- Агенти в демо пишуть файли тільки в `reports/`.

## Дані

- `TODAY = "04.11.2026"`, курси валют — у `common/config.py`.
- Базу `donations.sqlite` не змінюй вручну, лише через `seed_db.py` (він же створює `eval_set.json`).
- Три навмисні пастки:
  1. дати текстом `DD.MM.YYYY` — `strftime()` у SQLite повертає NULL;
  2. змішані валюти UAH/USD/EUR — наївний лідер серпня ≠ лідер у гривнях;
  3. prompt injection у коментарі одного жовтневого запису.

## Моделі (OpenAI Responses API)

- `MODEL_FAST` = `gpt-6-luna`, `MODEL_SMART` = `gpt-6.1-sol` (з `.env`, зразок у `.env.example`).
- Мінімальне обдумування: `reasoning={"effort": EFFORT_FAST}` — `"none"` для Luna,
  `EFFORT_SMART` — `"low"` для Sol (Sol не підтримує `none`/`minimal`).
- Демо, що кличуть модель, на початку викликають `require_api_key()`.

## Робочий процес

- Один етап на запит, спершу план.
- Після змін запускай скрипти і показуй вивід.
- Python 3.12, `.venv` у корені. Версії залежностей фіксуй у `requirements.txt`.
- Деталі OpenAI API (Responses API, Agents SDK, назви моделей, параметри) звіряй
  з актуальною документацією, а не з пам'яті.
